# 🪔 Vandan — वंदन

Personalized video greeting card platform for WhatsApp. Users create beautiful cards with their name, share directly on WhatsApp.

**Live:** https://vandan-app.vercel.app

## Structure

```
vandan-app/       → React web app (Vite + React 19)
vandan-videos/    → Remotion video renderer (50 videos with music)
```

## Quick Start

```bash
# Web App
cd vandan-app && npm install && npm run dev

# Generate Videos
cd vandan-videos && npm install && npm run render:all
```

## Tech Stack

React 19 · Vite · Remotion 4 · Supabase · Vercel
